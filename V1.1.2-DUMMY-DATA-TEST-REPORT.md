# Mongo Developer V1.1.2 — Dummy Test Data Validation

## Feature

Built-in resettable MongoDB practice database: `dummy_test_data`.

## Seed scope

- 17 collections
- 350 expected documents
- Related datasets for joins / `$lookup`
- Nested objects, arrays, booleans, numbers, nulls and BSON dates
- Unique, lookup-oriented and compound indexes

## Safety behaviour

- Automatic install is limited to the first writable LOCAL connection.
- Local detection is limited to `localhost`, `127.0.0.1` and `::1` style URIs.
- Remote connections are never modified automatically.
- Read-only profiles cannot install or reset the practice database.
- Manual reset is hard-coded to drop/recreate only `dummy_test_data`.
- A local persisted seed marker means deleting the database later does not silently recreate it; the UI changes to an Install button.

## Environment limitation

The full Go test suite could not be executed in this Linux sandbox because the repository requires Go 1.25 and its Go/Wails/MongoDB modules are not cached; outbound module downloads are disabled here. The existing Windows release gate remains authoritative and runs `go mod verify`, Go tests, frontend tests/build and the Wails/NSIS build on the user's Windows environment.
