# Mongo Developer V1.5.0 — Manual Release Test

Use a local writable MongoDB connection and the resettable `dummy_test_data` database for destructive tests. Do not use production data.

## 1. Install / version

- Build with `BUILD-INSTALLER.cmd` and require `ALL RELEASE-GATE TESTS PASSED` plus `BUILD SUCCEEDED`.
- Confirm `dist\MongoDeveloper-Setup-1.5.0.exe` exists.
- Install and launch from the Start Menu.
- Confirm the corner says `v1.5.0`.

## 2. Connection / navigation

- Connect with `mongodb://127.0.0.1:27017/`.
- Confirm the connection health indicator shows Connected, latency and MongoDB version.
- Use Reconnect and confirm databases reload.
- Confirm Connections and Databases open compact and both dividers drag only within their bounded ranges.

## 3. Query-mode regression

Open `dummy_test_data -> developers`.

- SQL auto-runs `SELECT * FROM developers LIMIT 50;`.
- Switch SQL -> Eloquent -> SQL; Run must remain enabled.
- Switch through Find JSON -> Aggregation -> SQL -> Eloquent -> Find JSON; each mode must remain runnable.
- Ctrl+Enter runs the active query.
- Ctrl+L focuses the editor.
- Ctrl+Shift+F formats the query.

## 4. Saved Queries / history

- Edit a SQL query and press Save Query.
- Name it `Active developers`.
- Confirm it appears under Saved Queries with SQL + `dummy_test_data.developers`.
- Change to another query/mode, reload the saved query, and confirm its mode/text/namespace are restored without auto-running it.
- Run it and confirm History shows database, collection and duration.
- Delete the saved query and confirm it disappears.

## 5. Unsaved-work protection

- Edit a query without running it, then click another collection. Confirm the Discard unsaved changes prompt appears.
- Choose Cancel and confirm you stay on the current collection/query.
- Repeat and choose Discard changes; confirm navigation continues.
- Edit a document in the right drawer and repeat the collection-switch test.

## 6. Explain / index advice

Run a selective query against a field that has an index and press Explain. Confirm the modal shows a plan stage and execution counters. If the server reports an index scan, the index name should be shown.

Then use an unindexed practice field, for example a Find filter such as:

```json
{ "bio": "not-a-common-value" }
```

Press Explain. If MongoDB chooses COLLSCAN, confirm Mongo Developer labels it as a collection scan and, when suitable fields are available, displays a suggested index. Press **Review in Create Index** and confirm the existing Create Index dialog receives the suggestion but does not create it automatically. Cancel the dialog unless you deliberately want the test index.

## 7. Read-only aggregation safety

Create/use a read-only profile to the same local MongoDB server.

- Normal Find queries must work.
- Aggregation `[ { "$match": {} } ]` must work.
- Aggregation `[ { "$out": "should_not_exist" } ]` must be blocked before Run.
- Confirm collection `should_not_exist` was not created.

## 8. Document editing

- Create a disposable document.
- Confirm malformed JSON disables Save.
- Edit a scalar inline and save it.
- Edit nested JSON in the document drawer and save it.
- Duplicate the disposable document.
- Delete both disposable documents with confirmation.

## 9. Laravel / Eloquent

- Link a Laravel project.
- Confirm discovered model mapping appears for a matching collection.
- Run a supported Eloquent read query.
- Unlink the project and confirm both the Laravel screen and right sidebar clear immediately.
- Link it again if desired.

## 10. Backup / restore

- Back up `dummy_test_data`.
- Confirm a timestamped stored ZIP appears and Save As can create a second copy.
- Add a temporary document after the backup.
- Restore the stored backup and confirm the temporary document disappears.
- Backup All and confirm MongoDB system databases are excluded.
- Download Copy from a stored backup.
- Delete a stored ZIP and confirm MongoDB data remains intact.
- Restore from the external ZIP copy.

## 11. Diagnostics / errors

- Open Diagnostics and confirm version `1.5.0`, platform, connection, MongoDB version, config path and backup path appear.
- Confirm no connection password is shown.
- Press Copy Diagnostics and paste into Notepad.
- Enter malformed Find JSON and confirm validation includes useful parser detail; Copy Error should copy an execution error when one is shown.

## Release decision

Release only when every applicable section above passes. If one fails, fix only that release-blocking defect, increment the patch version, rebuild, and rerun this checklist from the start.
