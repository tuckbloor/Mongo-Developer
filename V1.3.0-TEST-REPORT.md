This sandbox has Go 1.23.2 while the project requires Go 1.25+, and the frontend package pins the Windows Rolldown binding. The authoritative final gate is therefore the normal Windows build:

```powershell
.\BUILD-INSTALLER.cmd
```

That build must pass Go tests, Vitest (including `eloquent.test.js`), frontend production compilation, Wails compilation and the NSIS installer step before treating the generated installer as the validated Windows build.
