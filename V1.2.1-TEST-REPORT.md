# Mongo Developer V1.2.1 — Query Editor UX Hotfix Validation

## Behaviour restored

- Collection click switches to SQL mode.
- The normal SQL textarea receives `SELECT * FROM <collection> LIMIT 50;`.
- The query executes automatically on collection selection.
- No SELECT/FROM/JOIN/WHERE/ORDER BY/LIMIT section editor is displayed.
- Direct SQL edits are supported and mark the query dirty until Run Changes.

## Document safety

- New-document JSON is validated before insert.
- Drawer JSON is validated before replace.
- Save is disabled while JSON is malformed.
- Root arrays, scalar values and null are rejected as document JSON.
- The existing `_id` remains protected on replacement.

- SQL translator standalone suite: PASS.
- JSON document validator standalone suite: PASS.
- App.vue script syntax check: PASS.
- Static check confirms section-editor controls are absent from App.vue.
