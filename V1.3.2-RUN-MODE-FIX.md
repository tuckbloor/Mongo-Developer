# Mongo Developer V1.3.2 — Query Mode Run-State Fix

## Fixed
- Switching from Eloquent back to SQL no longer leaves the SQL Run button disabled.
- SQL Run is always available when the current SQL is valid.
- Edited SQL still shows `Run Changes`; unchanged SQL shows `Run` / `Run Query`.
- Result-origin tracking now distinguishes SQL, Eloquent, aggregation and find results.
- Returning to SQL after running Eloquent shows a clear prompt to run the SQL rather than incorrectly claiming the displayed results match it.

## Preserved
- Collection click still auto-runs `SELECT * FROM <collection> LIMIT 50`.
- SQL JOIN support remains.
- Eloquent query mode remains.
- Compact auto-growing SQL editor remains.
- Compact draggable sidebars remain.
- Laravel link/model discovery and unlink behaviour remain.
- JSON document validation remains.
