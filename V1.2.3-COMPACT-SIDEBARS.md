# Mongo Developer V1.2.3 — Compact Sidebars

- Connections is compact by default (210px), expandable to 300px.
- Databases is compact by default (220px), expandable to 285px.
- Expand/compact choices are remembered in localStorage.
- Pane headers are reduced to fit their content more closely.
- Laravel Project now has Unlink Project in both the Laravel workspace and right-side card.
- Unlink only forgets the GUI link; it never deletes or edits the Laravel project folder.
- Query editor, results table, dummy_test_data, JSON validation, CRUD and Mongo backend remain unchanged from V1.2.2.
