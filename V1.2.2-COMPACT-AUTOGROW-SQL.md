# Mongo Developer V1.2.2 — Compact Auto-Grow SQL Editor

- SQL editor starts at approximately five visible lines (123 px).
- Clicking a collection still auto-loads and runs the normal three-line `SELECT * / FROM / LIMIT` query.
- Editing SQL to add more lines grows the editor automatically.
- Shortening the SQL shrinks it back toward five lines.
- Automatic growth is capped at 480 px and also respects the available viewport so the results pane keeps useful space.
- The existing splitter and Expand/Restore controls remain available.
- A new localStorage key prevents the previous large saved editor height from overriding this compact default.
- Document JSON validation from V1.2.1 is unchanged.
