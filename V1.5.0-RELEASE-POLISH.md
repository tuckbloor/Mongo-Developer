# Mongo Developer V1.5.0 — Release Polish

V1.5.0 is the feature-freeze candidate intended for manual testing before public release.

## Explain / index advice

The Documents workbench now has an Explain action for Find JSON, Aggregation, SQL and Eloquent. SQL/Eloquent are translated first and the resulting MongoDB operation is explained. The UI shows the winning stage, index name when available, documents/keys examined, returned count and execution time. A collection scan can produce a candidate index from filter/sort fields. Suggested indexes are advisory: Mongo Developer never creates one just because Explain recommended it; **Review in Create Index** opens the existing index form for deliberate review.

## Saved Queries

Save the current query with a name. Each record keeps mode, database, collection, query text, Find sort and timestamp. Up to 100 saved queries are retained locally. Loading a saved query restores its namespace/mode and leaves it unexecuted until Run is pressed.

## Unsaved-change guard

Changing connection or collection while a query/document has uncommitted edits now requires an explicit **Discard changes** choice. Query modes retain independent dirty state. An application close also requests browser/WebView unsaved-change protection where supported.

## Diagnostics / connection health

The top bar now exposes Diagnostics. It reports version, platform, Go runtime, selected connection name and password-free URI, connected state, latency, MongoDB server version, access mode, Laravel link/package state, config path and backup path. Copy Diagnostics makes support reports easy to paste. The context bar shows connection latency/version and offers Reconnect when health is unavailable.

## Query errors and history

JSON parse errors include line/column when the parser supplies a character position. Backend query failures are labelled with query mode and database.collection. Error toasts include Copy. Query history now retains up to 50 distinct namespace/query entries with execution duration.

## Keyboard workflow

- Ctrl+Enter — run current query.
- Ctrl+K — focus global filter.
- Ctrl+L — focus query editor.
- Ctrl+Shift+F — format current query.
- Ctrl+S — save an editable document, or open Save Query from the workbench.
- Esc — close the active saved-query/explain/diagnostics/document tool or leave expanded results/query view.

## Read-only hardening

Aggregation stages `$out` and `$merge` are treated as write operations. On read-only connection profiles they are rejected in the editor and enforced again in the Go backend.

## Feature freeze

After V1.5.0 passes its Windows build and manual test checklist, no additional feature should be added before release. Only release-blocking defects should change the candidate.
