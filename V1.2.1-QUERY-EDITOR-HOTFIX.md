# Mongo Developer V1.2.1 — Query Editor UX Hotfix

- Restores the clean SQL text editor as the primary collection view.
- Clicking a collection automatically shows and executes `SELECT * FROM <collection> LIMIT 50;`.
- Removes the per-clause SELECT/FROM/JOIN/WHERE/ORDER BY/LIMIT edit controls from the visible workbench.
- SQL remains directly editable in the normal query box; edited SQL requires Run Changes.
- Keeps V1.2.0 table/document editing, row actions, drawer, column controls, resizable panes and dummy_test_data.
- Validates document JSON before insert/replace. Save is disabled while JSON is invalid or the root is not a JSON object.
