# Mongo Developer V1.3.0 — Laravel Bridge + Resizable Navigation

## Navigation

- Connections starts at 158px (about 25% smaller than V1.2.3), bounded to 145–330px.
- Databases starts at 165px (25% smaller than V1.2.3), bounded to 150–360px.
- Drag the vertical divider on either pane to resize it.
- Double-click the divider to return to the compact default.
- Widths are remembered locally.

## Laravel bridge

- A linked project is remembered between launches.
- Unlink clears the shared Laravel state immediately and removes the remembered link. It never deletes the Laravel project or model files.
- `app/Models` is scanned for model class, namespace, connection, collection/table override, MongoDB Eloquent base class, and common relationship methods.
- The right sidebar shows the model mapped to the active MongoDB collection.
- The Laravel tab shows project checks and collection → model mapping.
- Generated models use the current MongoDB Laravel `$table` collection override.
- Generated models avoid the deprecated MongoDB `array` cast.
- After model generation the Laravel project is rescanned so the new mapping appears immediately.

## Eloquent query mode

Eloquent mode is a safe query preview/transpiler. It does not execute PHP. Supported read-chain methods:

- `query()`
- `where()`
- `whereIn()` / `whereNotIn()`
- `whereNull()` / `whereNotNull()`
- `orderBy()`
- `latest()` / `oldest()`
- `limit()` / `take()`
- `skip()` / `offset()`
- `select()`
- `get()` / `first()` / `count()`

Example:

```php
Developer::where('active', true)
    ->orderBy('name')
    ->limit(50)
    ->get();
```

Mongo Developer maps the model to its collection and translates the supported chain into native MongoDB aggregation stages.
